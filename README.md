# NovaOS

NovaOS is a highly customizable Android-based operating system. This repository contains the core customizations for the Advanced Customization Center.

## Features Implemented:
- **Status Bar Plus**: Battery Bar, Network Traffic Monitor, Status Bar Icon Toggles.
- **Quick Settings Pro**: Customizable QS Grid, Brightness Slider Position, Custom Header Images.
- **Lockscreen Mods**: Custom Clock Fonts, Double-tap to Sleep.
- **Navigation & Gestures**: Gesture Pill Width/Thickness, Volume Skip Tracks.
- **Advanced Reboot**: Integrated Recovery and Bootloader options.

## Built with
- AOSP / Android 13+
- SystemUI
- Settings App
